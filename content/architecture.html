Client Execution Lifecycle

Eager → Lazy → Delayed Explained

Phase 1 · Eager (LCP)

Paint Above-the-Fold in Under 1 Second

In scripts/scripts.js, loadEager() decorates semantic sections, sets body.appear, and awaits only waitForLCP(['hero']). Only styles/styles.css, scripts/aem.js, scripts/scripts.js, and the Hero block load in the critical path.

Phase 2 · Lazy (Blocks & Shell)

Decorate Below-the-Fold Without Blocking First Paint

Once LCP is painted, loadLazy() loads remaining block JS/CSS modules in parallel, fetches /nav.plain.html and /footer.plain.html fragments, loads web fonts and styles/lazy-styles.css, and observes blocks for RUM.

Phase 3 · Delayed (3s+ Martech)

Isolate Heavy Analytics, Tags & Chat Widgets

loadDelayed() schedules scripts/delayed.js after 3 seconds. Core Web Vitals RUM beacons, Adobe Launch / Tags, consent managers, and third-party widgets execute strictly after the page is fully interactive.

Code Bus & Content Bus

Zero-Build GitHub Deployment

Every push to GitHub syncs automatically via the AEM Code Sync GitHub App to Adobe’s Code Bus. Content edits sync to Content Bus via Sidekick, and images transcode automatically to WebP/AVIF on Media Bus.

Built-In SEO & Crawling

Edge-Rendered Semantic HTML, Sitemaps & Bulk Metadata

Edge Delivery delivers clean, crawlable HTML straight from the CDN with zero SPA hydration delay — Googlebot and AI crawlers see your <h1>, headings, links, and metadata on the very first byte.

  • Metadata & Open Graph: Every page’s Metadata table automatically generates <title>, description, canonical, and og:image tags; folder defaults & noindex rules live in /metadata.json.
  • Core Web Vitals: 100/100 Lighthouse scores directly strengthen mobile SEO rankings.
  • Sitemaps & Redirects: /sitemap.xml auto-updates from the Query Index, while /redirects.json preserves link equity on URL changes.
  • Structured Data & Media: Inject JSON-LD (FAQPage, Article, Product) from metadata/sheets, with auto-optimized WebP/AVIF images and author alt text.

Connect This Repo to Live Edge Delivery in 3 Minutes

Step-by-Step Cloud Activation

  1. Install the AEM Code Sync GitHub App on arunpayy/edge-delivery-demo.
  2. Choose your content store in the setup wizard (DA.live at da.live or Google Drive via fstab.yaml).
  3. Seed your index, nav, footer, and data/use-cases sheets (matching the exact structures under ./content/).
  4. Install the AEM Sidekick browser extension and click Preview → Publish.

Your live preview URL will be https://main--edge-delivery-demo--arunpayy.aem.page/ and production will be https://main--edge-delivery-demo--arunpayy.aem.live/.
