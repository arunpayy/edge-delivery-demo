How do authors create an Accordion in a document?

Insert a 2-column table headed Accordion. Every row’s left cell becomes the clickable summary, and the right cell becomes the expandable panel.

Does this block require any third-party JavaScript library?

No — it uses native browser <details>/<summary> semantics with under 25 lines of vanilla JavaScript.

Pre-Publish Content-Author Style Checklist

Heading Hierarchy & Page Structure

Use exactly one H1 per page, never skip heading levels (avoid jumping from H1 straight to H3), and never nest a block table inside another table.

Buttons, Links & Accessibility

Create a Primary button by placing a standalone link (or bold link) on its own line, and a Secondary button by making the standalone link italic. Always use descriptive link text (“Explore Enterprise Use Cases”, never “Click here”) and add concise alt text to meaningful images.

Fragments & SEO Hygiene

Use Fragment for shared site chrome and repeated banners (/nav, /footer, /fragments/cta-banner). Keep core SEO body copy directly on the host page so search crawlers index it in the initial HTML.

Safe Page Deletion & Publishing Flow

Always add and publish a row in /redirects.json before deleting or renaming a live URL. Follow Edit → Preview (*.aem.page) → Verify → Publish (*.aem.live).
